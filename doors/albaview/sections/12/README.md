### campana · Qué dibuja la campana

**Recorded type:** Representación de AlbaView

**Claim:** La campana es un dibujo para orientarnos en el tiempo, no la forma real del universo.

**Contribution:** En esta versión web, el eje usa η = log₁₀(t/1 año), de 0 a 105; el primer año se reúne en el vértice. Su anchura evoca la expansión: el código usa una aproximación de materia y constante cosmológica para el pasado y una apertura estilizada para el futuro. No representa a escala física todo el universo temprano.

**Limits:** El eje temporal usa η=log₁₀(t/1 año), de 0 a 105. El primer año queda agrupado fuera del eje. La anchura no mide el tamaño físico del universo. La altura comprime tiempos por una regla logarítmica; la anchura no mide tamaño real ni entropía. El dominio de la web no es el mismo que el de la figura impresa. El horizonte futuro queda abierto.
